# DWG Viewer

Офлайн преглед на чертежи (DWG/DXF) за iPhone, iPad и Windows. Без акаунт, без облак — файловете остават на устройството.

## Какво работи

- **DXF:** пълен изглед — слоеве, блокове, текст, размери, измерване в сантиметри.
- **DWG:** версия на файла и вграденият в него преглед (ако има такъв). Пълното векторно отваряне на DWG изисква библиотеката LibreDWG (GPL) и **още не е добавено**.
- История на последните 20 файла, тъмен/светъл фон, измерване с прихващане към върхове.

## Публикуване в GitHub Pages (за iPhone)

1. Създай хранилище (repo) и качи съдържанието на тази папка в корена му.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. След минута линкът е `https://<потребител>.github.io/<хранилище>/`.
4. На iPhone отвори линка в **Safari** и изчакай да се зареди (веднъж, с интернет).
5. Сподели → **Добави към началния екран**. Оттам нататък работи и в самолетен режим.

Забележки: приложението се отваря само от HTTPS линк (GitHub Pages е такъв), не като файл. Историята се пази отделно за Safari и за иконата на началния екран. iOS може да изчисти данните на уебсайт, ако не се ползва седмици.

## Windows (.exe)

Готовият файл е `DWG-Viewer.exe` — пуска се с двоен клик, отваря прозорец през Edge/Chrome (има ги на Windows 10/11) и не иска интернет. Всичко е вградено в .exe.

- Първо стартиране: Windows SmartScreen може да покаже „непознат издател“ (файлът не е подписан) → *Повече информация* → *Все пак стартирай*.
- Сглобяване от код: `windows\build.bat` (нужен е Go) или GitHub → Actions → *Build Windows exe* → Run workflow.

## Файлове

| Файл | За какво е |
|---|---|
| `index.html` | цялото приложение (без външни библиотеки) |
| `sw.js`, `manifest.webmanifest` | офлайн кеш и инсталиране като приложение |
| `icons/`, `apple-touch-icon.png` | иконите |
| `windows/` | код за Windows .exe |

След промяна на файловете увеличи номера в `sw.js` (`dwg-viewer-v1` → `v2`), за да се обнови кешът.
